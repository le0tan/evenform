## Evenform's license

Evenform's original code is released under **MIT**, with the full text in the
root [LICENSE](../LICENSE) and `license: "MIT"` in `package.json`.

MIT fits the source-first adoption model: users can copy, adapt, distribute, and
use components commercially while preserving copyright and license notices.
It aligns with shadcn/ui and VChart. Apache-2.0 would add an explicit patent grant
and additional conditions; no project requirement for that tradeoff was stated.
The project license does not replace third-party licenses or grant trademark
rights. [MIT terms](https://choosealicense.com/licenses/mit/).

## Other dependencies and assets

The Modules logo is owned by its creator, Tan Yuanhong, who confirmed on
2026-10-21 that the original artwork and project variants are MIT licensed.
See [brand assets](brand.md) for provenance and variants. The artwork license
does not grant trademark rights.

The project's MIT choice does not imply all dependencies are MIT. React Aria
and related packages use Apache-2.0; Lucide uses ISC with Feather-derived MIT
notices; Geist uses SIL OFL-1.1. Preserve the complete installed license files,
including any accompanying NOTICE text. FullCalendar's standard components are
used; premium resource/scheduler plugins are outside the adoption boundary.

The lockfile also contains MPL-2.0 packages such as build-time Lightning CSS and
native tooling. A lockfile entry is not proof of inclusion in browser output.
The Vite-generated inventory is based on emitted JS chunks; the distribution
script explicitly adds stylesheet/font inputs. Redistribution of native tools
or a changed bundle needs its own scope review, including any applicable
MPL-covered source obligations. Evenform does not vendor or modify those tools.

## Notices and reproducibility

The root [third-party notices](../THIRD_PARTY_NOTICES.md) describe source reuse,
dependency use, and reference-only boundaries. `licenses/sources.json` maps exact
package versions to reviewed upstream texts when npm omits them. Snapshots are
retained unchanged; unpinned URLs record the upstream file reviewed on the stated
date rather than a promise about future upstream contents.

Each build emits a full `THIRD_PARTY_NOTICES.md`, `third-party-licenses.json`,
and Evenform `LICENSE`. The generator retains package license and NOTICE files,
fills reviewed omissions, and fails on missing text or identifiers. JS package
metadata is combined with explicit shadcn/Tailwind/animation/font/calendar CSS
inputs. This is a distribution inventory, not a complete SBOM or a license
determination based only on an npm field.

Keep source notices and `licenses/` with copied source. Keep generated notices
with deployed or redistributed artifacts. Visible UI badges/credits are optional
for the reviewed MIT projects; the legal notices are not. Do not include external
reference screenshots in public assets merely because they were used during
development. Release preparation is described in [releasing.md](releasing.md).
