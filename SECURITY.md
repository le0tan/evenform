# Security policy

Evenform is pre-1.0. Security fixes target the latest source on the repository's
default branch; older snapshots do not have a separate support commitment.

For a suspected vulnerability, use **Security → Report a vulnerability** on this
repository if private vulnerability reporting is enabled. You can also report
privately to [leotan.yh@gmail.com](mailto:leotan.yh@gmail.com).
Do not disclose an exploit or sensitive data in a public issue.

Include the affected commit/version, a minimal reproduction, expected impact,
and any proposed mitigation. Redact credentials and personal or internal data.
Maintainers will coordinate a fix and disclosure as availability permits;
there is no guaranteed response SLA or bug-bounty program.

This repository's Showcase uses illustrative data and local browser state.
Consuming applications remain responsible for authentication, authorization,
sanitization, API transport, upload handling, and secure deployment.
