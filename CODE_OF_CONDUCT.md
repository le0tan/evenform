# Code of conduct

Evenform welcomes contributors of all backgrounds and experience levels. Treat
people with respect, give constructive feedback about the work, and make room
for different perspectives. Help keep discussions relevant and accessible.

Harassment, discrimination, threats, sexualized conduct, personal attacks,
doxxing, and publication of private information without consent are not welcome.
These expectations apply in project issues, pull requests, discussions, and
other spaces maintained by this project.

Maintainers may edit or remove harmful content, close disruptive discussions,
or restrict participation. They should explain decisions when doing so does not
expose private information or create additional harm. Enforcement should be
proportionate to the behavior and protect affected participants.

Report concerns through GitHub's reporting tools or contact a maintainer using
a private contact method listed on their public profile. Do not post another
person's private information in a public issue. Maintainers will handle reports
as privately as practical and may use GitHub moderation support where needed.
